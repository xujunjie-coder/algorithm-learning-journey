# 5×5 拉灯游戏：枚举第一行与逐行递推

## 题意抽象

棋盘上的灯用 `1` 表示亮、`0` 表示灭。按下一个位置时，该位置以及上下左右相邻位置都会翻转。需要求使全部灯变亮的最少操作次数；如果不能在 6 步以内完成，输出 `-1`。

## 数据范围与复杂度要求

棋盘宽度固定为 5，因此第一行只有 `2^5 = 32` 种按法。每种按法只需要处理 25 个位置，所以每组数据复杂度为 `O(2^5 × 5^2)`，`n <= 500` 时可以直接处理。

## 涉及知识点

- 枚举第一行；
- 逐行递推；
- 状态压缩：用 5 位二进制数表示第一行按法；
- 网格局部翻转；
- XOR 状态切换；
- 复制状态后分别尝试方案。

## 思路推导

第一行没有上一行可以决定它，因此枚举第一行的完整按法。`mask` 的第 `j` 位为 `1`，就按第一行第 `j` 列。

第一行处理完成后，从第二行开始扫描。如果上一行某个位置为 `0`，为了最终让它变成 `1`，必须按当前行对应位置。因为当前时刻只有当前行这个按钮还能够影响上一行该位置，所以这个选择是强制的。

处理完第五行后，检查第五行是否全为 `1`。若是，则当前 `mask` 对应一个合法方案，用它更新最小步数；否则丢弃该方案。

## 核心不变量或正确性

- 处理第 `i` 行时，第 `0..i-1` 行的按法已经确定；
- 处理完第 `i` 行后，第 `i-1` 行已经达到目标状态，后续不会再改变；
- 对固定的第一行按法，后续每一行的按法唯一确定；
- 所有完整方案都对应唯一的第一行按法，因此枚举 32 种第一行方案不会漏解；
- 最后一行没有下一行可以影响，所以最后一行全为 `1` 是当前方案合法的充要检查条件。

## 我的实现

程序使用 `press` 函数翻转自己和上下左右，并通过边界判断处理角落和边缘。`solve(mask)` 复制原棋盘，完成一个第一行方案的模拟，返回合法方案的操作次数或 `INF`。

## 时间与空间复杂度

- 每组数据：`O(2^5 × 5^2)` 时间；
- 额外棋盘空间：`O(5^2)`；
- 所有测试数据：`O(n × 2^5 × 5^2)`。

## 错误、反例与修复

### 1. 把翻转写成赋值

错误：

```cpp
b[xx][yy] = 1;
```

这会把灯强制设置为亮，不能表达“亮变灭、灭变亮”。修复为：

```cpp
b[xx][yy] ^= 1;
```

### 2. 翻转边界位置时没有判断下标

角落位置的上方或左方不存在，直接访问会越界。修复为只在下标属于 `[0, 4]` 时翻转。

### 3. 第一行没有完整确定就开始递推

第一行的 5 个位置共同构成一个 `mask`。必须先执行完这个 `mask` 对应的全部第一行按法，再递推后面几行。若按一个第一行位置就递推，之后再按第一行其他位置会改变已经处理过的状态，之前的递推结果就失效。

### 4. 逐行递推的目标条件写反

目标是让上一行变成 `1`，所以当：

```cpp
b[i - 1][j] == 0
```

时，才需要按当前行对应位置。之前写成判断 `b[i - 1][j]` 为真，会把已经亮着的灯再次按灭。

### 5. 最后一行的合法性判断写反

最后一行只要出现 `0`，当前方案就失败：

```cpp
if (b[4][j] == 0) return INF;
```

不能把出现 `1` 当成失败，也不能返回 `0`，因为 `0` 会被最小值统计错误地当成最优答案。

### 6. `solve` 返回值错误

合法方案必须返回实际操作次数 `step`，而不是固定返回 `0`：

```cpp
return step;
```

### 7. 第一行 mask 的枚举范围错误

正确范围是：

```cpp
for (int mask = 0; mask < (1 << 5); ++mask)
```

这会覆盖 `0..31` 的全部 32 种方案。不能从 `1` 开始，也不能使用 `<=`。

### 8. 没有对所有方案取最小值

不能只调用 `solve(mask)` 而丢弃返回值，应使用：

```cpp
answer = min(answer, solve(mask));
```

### 9. 多组数据没有重置答案和输出

每个棋盘都必须重新令 `answer = INF`，处理结束后再根据 `answer <= 6` 输出答案或 `-1`。

### 10. 字符数字转换写错

输入中的每个棋盘位置是字符 `'0'` 或 `'1'`，正确转换方式是：

```cpp
a[i][j] = c - '0';
```

如果误写成：

```cpp
a[i][j] = c - 'a';
```

得到的就不是 `0` 或 `1`，后续的 `if` 判断和 `^= 1` 翻转都会基于错误状态运行。`'a'` 只适合用于字母字符的相对编码，不能用于数字字符。

## 可迁移经验

遇到固定宽度、局部影响、后续选择会被前一行状态强制决定的网格题，可以尝试“枚举第一行 + 逐行递推”。写代码时把每个 `solve(mask)` 看成一个独立实验：复制原状态、执行方案、验证结果、返回代价。
