## 题意抽象

根据代码推断，题目要求使用“选或不选”的递归方式枚举集合 `{1,2,...,n}` 的所有子集。

## 涉及知识点

- 递归树；
- 选/不选分支；
- 回溯与恢复现场；
- 指数型枚举。

## 思路推导

每层处理一个数字 `cur`：

1. 将 `cur` 加入当前方案并递归；
2. 弹出 `cur`，恢复进入本层前的状态；
3. 不选择 `cur` 并递归。

当 `cur == n + 1` 时，数字 `1..n` 已全部完成选择决策，当前数组 `a` 就是一条完整方案。

## 错误、反例与修复

### 1. 递归终止条件提前

原代码使用 `cur == n`，但此时数字 `n` 还没有完成选或不选的决策。

修复为：

```cpp
if (cur == n + 1)
```

### 2. 终止后没有返回

原代码输出方案后继续执行下面的 `push_back` 和递归调用，导致递归无法停止，最终可能栈溢出。

修复为输出后立即：

```cpp
return;
```

### 3. 输出范围固定为 `n`

原代码使用 `i < n` 遍历 `a`，但 `a` 只保存当前被选中的元素，长度可能小于 `n`，会访问越界。

修复为：

```cpp
for (int i = 0; i < a.size(); ++i)
```

### 4. 回溯过程正确

```cpp
a.push_back(cur);
dfs(cur + 1);
a.pop_back();
dfs(cur + 1);
```

`pop_back` 正确恢复了进入当前层之前的状态，因此“选”和“不选”两条分支互不污染。

## 复杂度

方案数量为 `2^n`。如果每个方案都需要输出其元素，复杂度为 `O(n 2^n)`；递归深度为 `O(n)`。
