## 题意抽象

根据代码推断，程序需要输出数字 `1..n` 的所有排列。每个数字在一个排列中恰好出现一次。

## 数据范围与复杂度要求

代码使用 `N = 15` 的数组，但原题精确范围未提供。全排列数量为 `n!`；若每个排列都输出 `n` 个数字，时间复杂度为 `O(n * n!)`，递归深度和辅助数组空间为 `O(n)`。

## 涉及知识点

- 递归排列型枚举；
- 回溯与恢复现场；
- `flag` 数组记录数字是否已使用；
- 循环产生同层分支。

## 思路推导

`dfs(cur)` 表示正在填写排列的第 `cur` 个位置。通过 `for` 循环尝试每一个还没有使用的数字：

1. 将数字 `i` 放入 `a[cur]`；
2. 标记 `flag[i] = 1`，递归填写下一个位置；
3. 递归返回后将 `flag[i]` 恢复为 `0`；
4. 由 `for` 循环自动尝试下一个数字。

当 `cur > n` 时，所有位置都已填写，输出当前排列。

## 核心不变量或正确性

- 进入 `dfs(cur)` 时，`a[1..cur-1]` 是一个不重复的合法前缀；
- `flag[i] == 1` 当且仅当数字 `i` 已经出现在当前前缀中；
- 当前选择返回后恢复 `flag[i]`，保证其他分支可以重新使用数字 `i`；
- 每一层只选择未使用数字，因此每个排列中数字不重复；
- 每个位置依次尝试所有合法数字，因此每个排列恰好枚举一次。

## 我的实现

原代码的主要结构正确：`cur` 控制位置，`flag` 控制数字是否使用，`for` 循环枚举当前层的候选数字。删除多余的递归调用后，即为标准排列枚举结构。

## 时间与空间复杂度

- 叶节点数量为 `n!`；
- 输出每个排列需要 `O(n)`，总时间复杂度为 `O(n * n!)`；
- 递归栈、排列数组和标记数组均为 `O(n)`。

## 错误、反例与修复

### 1. 复原后多写一个 `dfs(cur + 1)`

错误代码为：

```cpp
dfs(cur + 1);
flag[i] = 0;
dfs(cur + 1);  // 多余
```

排列枚举中，`for` 循环已经负责产生当前层的下一种选择。复原后应该直接回到循环，尝试下一个 `i`：

```cpp
dfs(cur + 1);
flag[i] = 0;
```

如果额外递归，第二次进入下一层时当前数字已经被复原为未使用状态，后续递归可能再次选择它，生成重复数字；同时还会重复搜索同一层的子树。

## 可迁移经验

回溯的统一结构是“做选择 → 递归 → 撤销选择 → 尝试下一选择”。在排列枚举中，前三步由当前循环体完成，最后一步由 `for` 循环的下一次迭代完成；不要把循环产生的下一分支再次写成递归调用。
