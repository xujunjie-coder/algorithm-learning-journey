## 题意抽象

N×M 网格中 T 个感兴趣的摊点，可交换相邻位置，行、列均首尾相邻。判断能否让各行、各列的感兴趣摊点数分别相等；在最大满足要求的前提下求最少交换次数。

各行可均分当且仅当 T%N=0；各列可均分当且仅当 T%M=0。上下交换只改变行计数，左右交换只改变列计数；both 答案为两个方向代价之和。

## 数据范围与复杂度要求

截图没有完整数据范围，不能以代码数组长度代替题目约束。原实现 N=100005，假设维度小于 N。排序方案时间 O(N log N+M log M+T)，额外空间 O(N+M)，代价使用 long long。

## 涉及知识点

- 核心算法：环形均分转前缀和到中位数的绝对距离和。
- 辅助技巧：前缀盈亏、边界净流量、下界与构造匹配的最优性证明。
- 实现细节：逐个初始化变量、答案全链路使用 64 位整数、both 代价相加。
- 题目转化：用行／列计数分别建立均分模型；二维摊点交换的等价性依赖可安排实际交换，不将其推广成任意容量网络结论。

## 思路推导

设某个方向有 L 组，数量为 C[i]，目标 b=T/L。令 A[i]=C[i]-b，S[i]=Σ(j=1..i) A[j]。

链上前 i 组的总盈亏为 S[i]，只能经过第 i 条边与外部交换，因此必须至少跨边 |S[i]| 次。逐个把当前组调整到 b，向下一组传递的净数量恰好为 S[i]，所以最少次数为 Σ|S[i]|。S[L]=0，求和到 L 或 L-1 均可。

环上令 f_i 为第 i 组向后一组的净传递量，守恒得到 f_i-f_(i-1)=A[i]，从而 f_i=f_L+S[i]。最小化 Σ|f_i| 等价于 min_x Σ|S[i]-x|，x 取 S[1..L] 的中位数即可。

## 核心不变量或正确性

链的证明分两步：每条边至少需要 |S[i]| 次；贪心恰好达到这些下界。一次操作只跨一条边，因此求和不会重复计算一次操作。中间记账出现负数时，可调整实际传递次序，先从后方取得牌再向前传。

环与链的区别是前缀存在两个外部通道，不能固定从第一个位置开始用 Σ|S[i]|。例如 [0,3,3] 均分到 2，链代价 3，环代价 2。中位数可选某个 S[k]，此时第 k 条边净流量为 0，解释了最优方案可以断开一条边。

## 错误、反例与修复

### 1. 布尔变量未初始化

原句 `bool row,col = 0;` 只初始化 col。T%N 不为 0 时 row 从未被赋值却被读取，是未定义行为，不保证存在固定的错误输出。

修复：`bool row=(t%n==0), col=(t%m==0);`。

边界例：N=2,M=3,T=3，三点位于 (1,1),(1,2),(1,3)，正确结果 `column 0`；不可把此例说成必现未初始化错误。

### 2. both 只输出行代价

原句 `cout << "both " << ans1`，漏加 ans2。

最小清晰反例：N=M=2,T=2，感兴趣位置为 (1,1),(2,1)。行已经均分，列为 [2,0]，须一次水平交换，正确输出 `both 1`，原分支输出 `both 0`。

修复：输出 `ans1+ans2`。

### 3. 总代价使用 int

原版 `int solve`、`int ans`、`int ans1,ans2` 会截断大答案。即使 f[i] 是 long long，写回 int 仍有风险，最终 ans1+ans2 若以 int 运算也可能溢出。

修复：返回值、累计代价、接收答案的变量都使用 long long；中位数与 f 保持同一类型。原 `int z` 是否单独越界取决于范围，不作为已经证明的独立错误。

量级示例（非声称符合未展示的完整题目约束）：L=100000，前 50000 组各 2、后 50000 组各 0，平均 1，环形代价为 2500000000，超过 int 上限。

## 可迁移经验

- 看相邻搬运问题时，从“每个点缺多少”转向“每条边必须经过多少”。
- 直接遍历传给下一个与前缀和是同一个计算过程，均为 O(L)；公式主要帮助证明并推广到环。
- 用“下界 + 达到下界的构造”证明贪心。
- AC 是本次代码通过的证据，不自动等于独立掌握；后续宜复习前缀盈亏与边流量的关系。
