# IncDec Sequence（CH0304）

2026-11-11，《算法竞赛进阶指南》基本算法，前缀和与差分。书页给出 `n ≤ 10^5`。用户报告最终提交已 AC。保存的源码以最后一版为底稿，将 `ans1`、`ans2` 改为 `ll`，保留数组和 `y += (-diff[i])`。

## 题意与推导

一次可给闭区间 `[l,r]` 的所有数加 1 或减 1。求全体相等所需的最少操作数，以及在最少操作下能得到多少种常数数列。

记 `b[1] = a[1]`、`b[i] = a[i] - a[i-1]`，另设右侧哨兵 `b[n+1]`。区间加 `d` 时只需让 `b[l] += d`、`b[r+1] -= d`。原数组全相等当且仅当 `b[2..n]` 都为 0，共同值为 `b[1]`。设内部正差分总量为 `p`、负差分绝对值总量为 `q`。

- 第 1 类同时消去一单位正差分和一单位负差分，先配对 `min(p,q)` 次。
- 剩余 `|p-q|` 单位同号差分。第 2 类把一单位差分转到 `b[1]`，第 3 类把它转到 `b[n+1]`。每次操作对内部正、负差分总量各最多减少 1，所以至少需要 `max(p,q)` 次，这个构造恰好达到。
- 若 `p >= q`，设第 2 类做 `k` 次，最终公共值是 `a[1]+k`，其中 `k=0,1,...,p-q`。若 `p < q`，公共值是 `a[1]-k`。`+1` 来自整数区间的两个端点都计入，其中 `k=0` 表示剩余操作全用第 3 类。

也可以证明其他最优操作顺序只会得到同一范围内的公共值。固定目标值 `c`，在原数组两端各补一个始终不动的 `c`。扩展差分的正量是 `p + max(a[1]-c,0) + max(c-a[n],0)`，每次操作最多消去一单位。若 `c` 超出 `a[1]` 和 `a[n]` 之间的闭区间，这个正量就严格大于 `max(p,q)`。区间内的每个整数都能由上面的构造达到，且 `a[n]-a[1]=p-q`。

## 中途遇到的问题

| 问题 | 复现与修正 |
|---|---|
| 把负差分直接累加到 `y` | `3 5 2` 的相邻差分为 `+2,-3`，应得到 `x=2, y=3`。用 `y += (-diff[i])` 或 `y -= diff[i]`，正确输出为 `3` 和 `2`。 |
| 累计值用 `int` | 10 万个 `1,100000` 交替，正差分总量为 `4,999,950,000`。差分及累计量使用 `long long`。 |
| 累计值已用 `ll`，答案变量仍是 `int` | `max(x,y)` 计算在 64 位进行，赋给 `int ans1` 时仍会丢失范围。两个答案都使用 `ll`，或者直接输出表达式。 |
| 操作次数和结果种数混淆 | 第 2、3 类合计做 `|p-q|` 次，给第 2 类分配的次数从 `0` 数到 `|p-q|`，得到 `|p-q|+1` 种公共值。 |
