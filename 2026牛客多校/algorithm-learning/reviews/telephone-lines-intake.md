# Telephone Lines：题意与判定建模

- 来源：用户提供的完整题面截图，平台编号与 URL 未提供。
- 状态：题意讲解与建模阶段；未提供本题实现或评测结果；不计入已解决题目或正式模板来源。
- 范围：1 <= N <= 1000，1 <= P <= 10000，0 <= K < N，1 <= L <= 1000000。
- 图：无向图；从顶点 1 连接至 N。可以免去至多 K 条边的费用，支付金额为剩余边长度的最大值；没有付费边时支付 0；无法连接时输出 -1。

固定金额上限 limit，把每条边长度 z 转为 w=(z>limit)，超过上限的边记 1，其他记 0。1 到 N 的最短距离表示路线中最少的超限边条数。check(limit) 等价于 dist[N] <= K；不可达时返回 false。超限边全免费即可满足上限，故判定充要。

limit 增大时，每条边的转换代价不会增大，可行性保持 false...false,true...true。因此在 [0,maxEdge] 二分最小可行值；先判断 check(maxEdge)，失败表示原图不连通。

优先沿用学习中的 greater 小根堆 Dijkstra 实现 check；转换权重非负且只有 0/1，也可进一步用 0-1 BFS。Dijkstra 判定每次须重置距离和标记，并使用空堆；入堆的距离是超限边条数，不是原长度之和。

截图样例：K=1，路径 1→3→2→5 的长度依次为 4、3、9。limit=4 时转换为 0、0、1，判定通过；limit=3 时所有离开 1 的边与进入 5 的边均超限，至少需要两条免费边，判定失败。最小支付金额是 4。
