# 前缀和与差分

## 一维代码与边界

下标从 1 开始。前缀和用 `s[0]=0` 处理 `l=1`，差分数组多留一个 `n+1` 位置处理 `r=n`。下面是前缀和通用写法和差分写法，便于复习；本次前缀和练习的题目与实际提交源码待补。

```cpp
// 前缀和：O(n) 预处理，O(1) 查询闭区间和。
vector<long long> s(n + 1, 0);
for (int i = 1; i <= n; ++i) s[i] = s[i - 1] + a[i];
long long range_sum = s[r] - s[l - 1];

// 差分：O(n) 建表，O(1) 做一次闭区间加法，最后 O(n) 还原。
vector<long long> b(n + 2, 0);
b[1] = a[1];
for (int i = 2; i <= n; ++i) b[i] = a[i] - a[i - 1];
b[l] += d;
b[r + 1] -= d;
for (int i = 1; i <= n; ++i) a[i] = a[i - 1] + b[i];  // a[0] = 0
```

前缀和适合静态区间求和，差分适合批量区间加减后统一还原。差分的前缀和会恢复原数组。范围检查贯穿相减、累计、取绝对值和保存答案各环节。
