# 二分答案

## 解决的问题

当答案空间上的可行性具有单调性时，通过 `check` 在答案范围内二分，常见于“最大值最小”或“最小值最大”。

## 识别信号

- 答案是一个整数范围；
- 可以设计 `check(x)` 判断答案 `x` 是否可行；
- 可行性呈连续的真/假区间。

## 核心思路与不变量

最大可行值的模式：

```text
可行 可行 可行 | 不可行 不可行
```

可行时保留 `mid`，因此使用上取中点；不可行时排除 `mid`。

本题不能直接二分“恰好长度为 `x` 的回文”，因为奇数和偶数长度交错后不具备单调性。正确做法是分别二分：

- 奇数回文半径 `k`，长度为 `2k+1`；
- 偶数回文半长度 `k`，长度为 `2k`。

固定中心后，半径越小仍然是回文，所以这两个判定分别具有单调性。

## 标准模板

见 [binary-search-answer.cpp](../../templates/binary-search-answer.cpp)。

求最大可行值的核心形式：

```cpp
while (l < r) {
    long long mid = l + (r - l + 1) / 2;
    if (check(mid)) l = mid;
    else r = mid - 1;
}
```

## 常见变体

- 求最小可行值：可行时 `r = mid`，使用下取中点；
- 求最大可行值：可行时 `l = mid`，使用上取中点；
- 对奇偶、颜色、状态等互斥类别分别二分。

## 易错点

- `check(x)` 必须单调；
- `l = mid` 时必须使用上取中点；
- 初始区间要覆盖答案；
- 区间含义必须保持一致；
- 本题不能把所有长度放在一次二分中。

## 复杂度

若一次 `check` 为 `O(n)`，本题两次二分总复杂度为 `O(n log n)`。

## 关联题目

- [NC50987 Palindrome](../../problems/nowcoder-nc50987-palindrome.md)：分别二分奇数和偶数回文半径。

## 我的经验

最初的最大值二分使用了下取中点并执行 `l = mid`，在 `r = l + 1` 时会死循环。之后改用上取中点。

本题中我还因为对二分答案的单调性不熟，忽略了设计 `check` 函数前必须先确认单调性。最初把“是否存在长度恰好为 `x` 的回文子串”作为全局判定条件，但长度 `12` 不是回文并不意味着长度 `13` 不是回文，因此不能直接在所有长度上二分。

对应修改是把回文按奇偶分类，分别二分奇数回文半径和偶数回文半长度。固定中心后，若半径 `k` 可行，则更小半径也可行，判定才具有单调性。
