# 递归指数型枚举

## 解决的问题

通过对每个元素进行“选”或“不选”的决策，枚举所有子集、所有二进制状态或其他独立二分选择的组合。

## 识别信号

- 每个元素只有有限个独立决策，常见为选/不选；
- 需要输出或遍历所有方案；
- 方案数量呈 `2^n` 增长；
- 题目规模通常较小，因为输出本身可能达到指数级。

## 核心思路与不变量

令 `cur` 表示当前正在决定数字 `cur` 是否加入方案。对 `1..n` 全部作出决策后，下一层应为 `cur == n + 1`，此时 `a` 保存一条完整方案。

每条“选入”分支返回后，必须弹出刚加入的元素，再进入“不选”分支，保证两棵子树从同一个父状态出发。

## 标准模板

```cpp
vector<int> a;
int n;

void dfs(int cur) {
    if (cur == n + 1) {
        for (int x : a) {
            cout << x << ' ';
        }
        cout << '\n';
        return;
    }

    // 选 cur
    a.push_back(cur);
    dfs(cur + 1);

    // 恢复现场
    a.pop_back();

    // 不选 cur
    dfs(cur + 1);
}
```

## 常见变体

- 从 `0..n-1` 枚举时，终止条件为 `cur == n`；
- 只统计方案数量时，不需要保存 `a`；
- 选择顺序调整会改变输出顺序；
- 每个位置有多个选择时，分支数从 `2^n` 推广为 `k^n`。

### 固定选择数量的组合枚举

当题目要求从 `1..n` 中恰好选择 `m` 个数时，仍然对每个 `cur` 做“选/不选”决策，但可以加入可行性剪枝：

- `a.size() > m`：已经选得过多；
- `a.size() + (n - cur + 1) < m`：即使把剩余数字全部选上，也无法达到 `m` 个。

其中 `a.size()` 是当前已经选择的数量，`n - cur + 1` 是当前还未决策的数字数量。该变体的模板见 [递归组合枚举](../../templates/recursive-combination-enumeration.cpp)。

### 排列型枚举

当题目要求枚举 `1..n` 的全排列时，每层为当前位置选择一个尚未使用的数字：

```cpp
for (int i = 1; i <= n; ++i) {
    if (flag[i]) continue;
    a[cur] = i;
    flag[i] = 1;
    dfs(cur + 1);
    flag[i] = 0;
}
```

这里 `for` 循环负责产生同一层的不同选择。递归返回后只需复原 `flag[i]`，下一次循环迭代会自动尝试下一个数字，不能在复原后再次手动调用 `dfs(cur + 1)`。模板见 [递归排列枚举](../../templates/recursive-permutation-enumeration.cpp)。

## 易错点

- 终止条件必须与递归起点和决策范围对应；
- 到达终止条件输出后必须 `return`；
- 输出当前方案时遍历 `a.size()`，不能固定遍历 `n`；
- `push_back` 后必须在进入另一分支前 `pop_back`；
- 固定选 `m` 个时，必须同时判断“已选数量”和“剩余数量是否足够”；
- `cur` 表示下一个待决策的数字，因此从 `1` 开始时终止条件可以写成 `cur > n` 或 `cur == n + 1`，但必须和递归起点保持一致；
- 排列枚举中，`for` 循环已经负责产生下一条分支，复原后不能额外递归；
- 指数型枚举不适合大规模 `n`。

## 复杂度

递归树有 `O(2^n)` 个方案。若每个方案都输出全部元素，时间复杂度为 `O(n 2^n)`，额外递归栈和方案空间为 `O(n)`。

## 我的经验

本题中我通过 `cur` 的含义理解递归边界：`cur` 是下一个待决定的数字，因此当 `cur == n + 1` 时才说明 `1..n` 全部处理完毕。

本次组合枚举中，`a.size()` 表示已经选出的数量，`n - cur + 1` 表示还可以决策的数量。剪枝的本质是提前排除不可能达到恰好 `m` 个选择的递归分支。

本题实际调试中曾把数量可行性剪枝误写成 `if (cur > n) return;`。需要区分：`cur > n` 只负责判断所有数字是否已经决策完；`a.size() > m` 和 `a.size() + (n - cur + 1) < m` 才负责判断当前分支是否还有可能选出恰好 `m` 个数字。

排列枚举中又遇到过在 `flag[i] = 0` 后多写一次 `dfs(cur + 1)` 的问题。应记住“做选择、递归、撤销选择、循环尝试下一个选择”的结构：回溯负责复原，`for` 循环负责下一分支。
