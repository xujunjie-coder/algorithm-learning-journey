# 杨图、标准杨表与勾长公式

## 解决的问题

给定左对齐、各行长度从上往下不增加的形状，用 1 到 N 恰好各一次填格子，要求每行向右、每列向下严格递增，计算不同填法。

## 术语：杨氏矩阵、杨图和标准杨表

“杨氏矩阵”在不同教材中可能指行列有序的矩阵或广义杨表，使用时应先明确具体定义；本题准确对应“标准杨表计数”。不要把所有行列有序矩阵都直接套用本公式。

- **杨图（Young diagram）**：只有形状，没有数字。若各行格子数为 λ=(λ1,...,λk)，要求 λ1>=...>=λk>0，各行左对齐，这个 λ 是 N 的整数分拆。
- **杨表（Young tableau）**：在杨图格子中填数；根据填数规则还有不同类别。
- **标准杨表（standard Young tableau）**：将 1,...,N 无重复地填满杨图，每行从左到右递增、每列从上到下递增。

例如形状 (3,2,1)：

```text
杨图：          一种标准杨表：
□ □ □           1 2 4
□ □             3 5
□               6
```

本题用 1 表示最高者，所以身高递减恰好对应编号递增；每个合法合照对应一个标准杨表。若填的是实际身高，方向相反，但按身高排序映射编号即可。

## 勾长是什么

一个格子的勾由它自身、同一行右侧所有格子、同一列下方所有格子组成；不包括左侧、上方或右下角其他列的格子。勾长是这些格子的总数：

\[
h(i,j)=1+\text{右侧格子数}+\text{同列下方格子数}.
\]

若 i、j 均从 0 开始，n[i] 为第 i 行长度，则右侧有 n[i]-j-1 格，加上自己是 n[i]-j。下方第 r 行存在第 j 列，当且仅当 n[r]>j：

```cpp
ll h = n[i] - j;
for(int r = i+1; r < k; ++r)
    if(n[r] > j) ++h;
```

形状 (3,2,1) 的每格勾长为：

```text
5 3 1
3 1
1
```

## 勾长公式是什么

设杨图共有 N 格，标准杨表数量为：

\[
f^\lambda=\frac{N!}{\prod_{(i,j)\in\lambda}h(i,j)}.
\]

例如 (3,2,1) 的数量是 6!/(5×3×1×3×1×1)=16。

这是一个组合数学定理，不是将 N! 按互相独立的局部大小约束逐一相除的朴素推理；各格约束有依赖。当前学习只覆盖识别、公式使用和实现，未学习完整证明。来源：[MIT 18.212 第三讲，标准杨表与勾长公式](https://ocw.mit.edu/courses/18-212-algebraic-combinatorics-spring-2019/001cbc64a3dc76c564624cd3be283148_MIT18_212S19_lec3.pdf)。

## 前提与限制

该公式用于普通杨图形状的标准杨表计数。不能直接用于任意缺格图、任意带重复数字的行列有序矩阵或斜杨表。输入需先确认形状、编号范围和严格递增条件。

## 核心思路与不变量：先约分，再乘积

本题 N<=30，但 30! 超过 long long。最终结果小不代表中间阶乘小。把 1...N 分别存入 a[1...N]，每计算一个勾长 h，就依次用 gcd(a[t],h) 消去共同因子：

```cpp
for(int t = 1; t <= sum && h > 1; ++t){
    ll g = gcd(a[t], h);
    a[t] /= g;
    h /= g;
}
```

不变量：剩余分子因子乘积除以剩余分母乘积的值不变。由于所有勾长的乘积整除 N!，当前勾长的质因数可以从尚未消耗的分子因子中全部取出，处理完必有 h=1。

例如分母 6 可先与分子 2 约出公因数 2，剩余 3 再与分子 3 消去；不要求某个分子独自整除原始 h。每次修改的 a[t] 必须保留，不能处理下一个格子时重新初始化。

全部分母约完再乘剩余 a[t]。这些因子都是正整数，任意部分乘积不超过最终乘积；本题保证最终值适合无符号 32 位，long long 足够。

## 复杂度

N 个格子，每格扫描至多 k 行计算勾长、至多 N 个因子做 gcd。时间 O(Nk+N² log N)（gcd 按整数欧几里得算法估计），空间 O(N+k)。本题 N<=30。
