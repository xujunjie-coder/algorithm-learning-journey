# 回溯搜索与最优性剪枝

## 解决的问题

小规模约束分配与最优化：依次处理对象，枚举每一步的合法选择，维护当前最优答案。

## 识别信号

对象数量小；各选择相互影响；需要全局最优而简单贪心缺乏依据；存在可安全提前排除的分支。

## 前提与限制

必须证明分支覆盖、不变量成立、剪枝不丢失更优解。搜索最坏仍可能很慢，不能因 n 小就认为一定 O(2^n)。

## 核心思路与不变量

`dfs(cur,cnt)`：前 cur-1 个对象处理完，本层只决定对象 cur；循环变量 i 枚举容器。共享数组在递归返回后恢复原值，局部传值参数不用人为改动本层值。

若优化目标 cnt 在后续只增不减，已有合法最优上界 ans，则 cnt>=ans 时可以返回（只求最小值，不统计全部最优方案）。

## 标准模板

见[经过本地验证的装箱实例模板](../../templates/dfs-bin-packing.cpp)。不能直接复制其容量判断去解决其他约束，应保持“合法判断 → 修改 → 递归 → 恢复”的合同。

## 常见变体

- 等长分组（木棒）：先固定组长，再用 dfs(start,cur_len,fineshed) 选段；同组从 i+1 继续，新组从 0 开始。局部 last=-1 记录本层失败过的长度，不能赋 used[i]，也不能各层共享。
- 无编号的组：新组固定包含剩余第一段，所有包含它的方案失败后，不必更换开头。
- 恰好补满失败：P+x 与 P+B 中 sum(B)=x，交换单段 x 和组合 B 不影响可行性。因此单段补满后的后续搜索失败，可以直接结束当前调用。必须在递归返回、恢复、排除成功之后执行。
- 循环外 return 代表试完所有兄弟分支；循环内失败剪枝代表提前省掉剩余兄弟。子调用返回 false/未置 found，表示它负责的整棵子树失败，不只一次直接尝试失败。

- 先安排约束更紧的对象，改变搜索顺序以更早剪枝，仍保留所有合法选择。
- 同容量容器状态相同时可考虑等价分支去重，但须单独证明；本次模板未加入。
- 开始可用 dfs(1,0) 表示尚未开车；本次保留用户 dfs(1,1) 的一辆空车语义，不混用边界。

## 易错点

- cur 是对象编号，i 是容器编号；读取重量用 c[cur]。
- 新容器是循环外的一条独立分支，不属于某个容器的 else。
- 不在使用 cnt 为上界的循环里 cnt++；下一层传 cnt+1。
- 整数数组赋容量用 fill，不用任意值 memset。
- 即使新容器从全局数组里取出，也应明确它的初始值及回溯后恢复的值。

## 复杂度

装箱搜索最坏为指数规模，可用保守 O(n*(n+1)^n) 上界说明不能保证确定的快速运行；数组和栈 O(n)。剪枝实际收益与重量分布有关。状压装箱的确定 O(n*2^n) 不可套到 DFS 上。
