# 字符串哈希

## 解决的问题

将字符串或子串映射为整数，使子串相等判断可以从逐字符比较降为近似 `O(1)`。

## 识别信号

- 需要频繁比较两个子串是否相等；
- 需要判断一个区间与其反串对应区间是否相等；
- 直接逐字符比较会导致 `O(n^2)` 或更高复杂度。

## 核心思路与不变量

多项式哈希：

```cpp
h[i] = h[i - 1] * BASE + value(s[i]);
power[i] = power[i - 1] * BASE;
```

闭区间 `[l, r]` 的哈希为：

```cpp
h[r] - h[l - 1] * power[r - l + 1]
```

若使用反串判断回文，原串区间 `[l, r]` 对应反串区间：

```cpp
[n - r + 1, n - l + 1]
```

## 标准模板

见 [rolling-hash-string.cpp](../../templates/rolling-hash-string.cpp)。模板使用 0-based 闭区间，和本题的 1-based 实现不同，使用时注意下标语义。

## 常见变体

- 单模哈希；
- `unsigned long long` 自然溢出哈希；
- 双哈希降低碰撞概率；
- 正向哈希 + 反向哈希判断回文。

## 易错点

- 前缀和不是多项式哈希，不能混用查询公式；
- `rf` 是反串的前缀哈希，不是原串的后缀数组；
- 回文比较必须映射反串区间；
- 闭区间循环容易误写成 `r < n`；
- `unsigned long long` 哈希存在理论碰撞风险。

## 复杂度

预处理 `O(n)`，单次子串比较 `O(1)`，空间 `O(n)`。

## 我的经验

本题最初把前缀字符和与多项式哈希查询公式混用，随后修正为多项式哈希，并补上反串区间映射。
