# 质因数分解与约数和

## 解决的问题

计算 (A^B) 的所有正约数之和，通常要求对一个模数取模。

## 识别信号

- 目标数是 (A^B)，指数很大，不能展开；
- 要求约数和或约数个数；
- (A) 的范围允许试除分解；
- 结果需要取模。

另一个应用：对整数根式做化简，把质因数指数分成 `cot/2` 对与 `cot%2` 个剩余因子。此时不需要约数和公式，详见[整数根式化简](整数根式化简.md)。

## 核心思路与不变量

若：

\[
A=\prod_i p_i^{c_i},
\]

则：

\[
A^B=\prod_i p_i^{c_iB}.
\]

约数和函数具有乘法性：

\[
\sigma(A^B)=\prod_i(1+p_i+p_i^2+\cdots+p_i^{c_iB}).
\]

因此只需要：

1. 试除分解 (A)；
2. 对每个质因子计算等比数列和；
3. 把各个因子的结果相乘并取模。

## 标准模板

```text
factorize(A) 得到 (p, count)
answer = 1
for each (p, count):
    answer *= geometric_sum(p, count * B)
    answer %= MOD
若试除后剩余 x > 1，则 x 是一个指数为 1 的质因子：
    answer *= geometric_sum(x, B)
```

等比数列和使用：

\[
S(c)=1+p+\cdots+p^c.
\]

当 (c=2m) 时：

\[
S(2m)=S(m)(1+p^m)-p^m.
\]

当 (c=2m+1) 时：

\[
S(2m+1)=S(m)(1+p^{m+1}).
\]

## 易错点

- 直接计算 `sum(A, B)` 只得到 (1+A+cdots+A^B)，当 (A) 为合数时不等于 (sigma(A^B))；
- 统计质因子次数时必须使用 `while (x % p == 0)`，不能写成 `while (x > 0)`；
- 分解过程中要持续修改同一个剩余值 `x`，不能每轮重新令 `x = A`；
- 试除结束后要处理剩余的质因子；
- 每次乘法和递归返回值都要及时取模；
- 分治等比和按照指数 `c` 的奇偶性分支，而不是按照底数 `p` 的奇偶性分支。

## 复杂度

- 质因数分解：最坏 (O(\sqrt A))；
- 快速幂：(O(\log e))；
- 当前分治等比和模板：(O(\log^2 e))；
- 额外空间：递归深度 (O(\log e))。
