# 欧几里得算法（最大公约数）

## 解决的问题

求两个整数的最大公约数，常用于把分数约成最简形式。

## 识别信号

- 需要求两个整数的最大公约数；
- 需要约分：分子、分母同时除以它们的最大公约数。

## 前提与限制

- 计算取余时，第二个数不能为 0；
- 化简分数时，分母必须非 0；
- 下面的 `long long` 实现假设输入绝对值不为 `LLONG_MIN`，并且不同时为 0。

## 核心思路与不变量

一次带余除法写成：

\[
a=qb+r,\qquad 0\le r<b.
\]

若整数 `d` 同时整除 `a` 和 `b`，那么它也整除：

\[
r=a-qb,
\]

因为 `d` 整除 `a`，也整除 `qb`，所以它整除两者之差。反过来，若 `d` 同时整除 `b` 和 `r`，那么它也整除：

\[
a=qb+r.
\]

所以 `(a,b)` 与 `(b,r)` 的公约数集合相同，最大公约数不变：

\[
\gcd(a,b)=\gcd(b,a\bmod b).
\]

每次余数都比除数小，因此不断替换后会到达余数为 0 的情况。此时 `gcd(a,0)=|a|`，当前的 `a` 就是最大公约数。

例如：

```text
18 = 1 × 12 + 6
12 = 2 ×  6 + 0
```

因此 `gcd(18,12)=gcd(12,6)=6`。

## 实现示例

```cpp
long long gcdll(long long a, long long b) {
    if (a < 0) a = -a;
    if (b < 0) b = -b;

    while (b != 0) {
        long long r = a % b;
        a = b;
        b = r;
    }
    return a;
}
```

### 用最大公约数约分

分数 `p/q` 先把分母调整为正，再同时除以 `gcd(|p|,q)`。若化简后 `q==1`，就只输出整数 `p`。

```cpp
if (q < 0) {
    p = -p;
    q = -q;
}

long long g = gcdll(p, q); // 约分时 q 必须非 0
p /= g;
q /= g;

if (q == 1) cout << p;
else cout << p << "/" << q;
```

例如 `18/12` 化为 `3/2`，`-6/8` 化为 `-3/4`，`10/5` 输出为 `2`。

## 易错点

- 取余之后，下一轮要令 `a=b, b=r`；
- 负数参与约分前要统一符号，通常要求分母为正；
- 分数分母为 0 时不能约分；
- `gcd(0,q)=|q|`，所以 `0/q` 在 `q!=0` 时可约成 `0/1`；
- 若输入可能达到 `LLONG_MIN`，不能直接用 `-a` 取绝对值，需要改用无符号整数处理。

## 复杂度

- 时间复杂度：`O(log(min(|a|,|b|)))`；
- 额外空间：`O(1)`。
