# 整数根式化简

## 解决的问题

对非负整数 n，求 `sqrt(n)=outside*sqrt(inside)`，使 inside 不含大于 1 的平方因子。

## 识别信号

根式精确输出、提出平方因子、根号内无平方因子、判断根号能否完全开出。

## 前提与限制

输入 `n>=0`，负数应先按题意判断无实数平方根。`n=0` 特判为 `{0,1}`。试除适合本题 `n<=5000000`，不适合接近 `long long` 上限的大质数。

## 核心思路与不变量

质因数分解 `n=∏p^cot` 后，每种质因子的指数分成：

```text
cot = 2*(cot/2) + cot%2
outside *= p^(cot/2)
inside  *= p^(cot%2)
```

例如 `72=2^3*3^2`，提出一个 2 和一个 3，根号内剩 2，得到 `6*sqrt(2)`。最终满足 `原n=outside²*inside`，inside 的每个质因子指数都为 1。

试除时，已经处理的质因数全部从剩余 n 中除去。结束后若 `n>1`，它是剩余的单个质因子，必须乘入 inside。

## 标准模板

- [根式化简模板](../../templates/square-root-simplification.cpp)：`simplifySqrt(n)` 返回 `{outside,inside}`，保留用户 `cot` 命名与从 1 开始的循环。
- 若 `inside==1`，平方根为整数 outside，完全平方数也可以直接从化简结果识别。
- 对需要大量单独判断平方数的场景，可先算整数平方根再检查 `k*k==n`。本题数值小，原代码中的 `sqrt` 判断适用；大整数不能直接推广，需处理精度和乘法溢出。

```cpp
for (int i = 1; i <= cot / 2; ++i) outside *= p;
// 等价于 for (int i = 0; i < cot / 2; ++i)
```

## 常见变体

若表达式为 `sqrt(n)/mu`，先化简根号，再把 `outside/mu` 约分。根号内的 inside 不能跟根号外的分母直接约掉。

## 易错点

- 必须写 `while(n % p == 0)`；`while(n / p)` 只是检查商非零，会错误整除并破坏 n。
- `p<=n/p` 避免 `p*p` 溢出；本题 `p>=2`，除数不会为零。
- 不要漏掉试除结束后 `n>1` 的处理。
- 根式系数的四种输出：`sqrt(r)`、`u*sqrt(r)`、`sqrt(r)/v`、`u*sqrt(r)/v`。
- 有理部分为零时，仍必须输出根式和换行。

## 复杂度

最坏时间 `O(sqrt(原n))`，额外空间 `O(1)`。正式模板虽然用 `long long`，但时间复杂度没有因此改变。
