# 最简分数与符号规范

## 解决的问题

把整数分子、分母组成的分数 `zi/mu` 化为唯一的最简形式，用整数精确表示结果。

## 识别信号

要求最简分数、分母为正、整数不带 `/1`，或同一结果需要统一字符串表示。

## 前提与限制

- `mu != 0`。
- 正式模板使用 `long long`，输入不能是 `LLONG_MIN`，因为直接取相反数会溢出。
- 模板只做约分，不包含分数加减乘除；若增加这些操作，交叉乘法需要另查溢出。

## 核心思路与不变量

先在分母为负时同时改变分子、分母符号；再除以 `gcd(|zi|,mu)`。两步都不改变分数值，结果分母为正且分子分母互质。

`0/q` 自动变为 `0/1`，不必额外判断。约分只依赖欧几里得算法，不需要浮点除法。

## 标准模板

- [分数约分模板](../../templates/fraction-reduction.cpp)：`huajian(zi,mu)` 返回 `{分子,分母}`。
- 此文件通过相邻文件包含[最大公约数模板](../../templates/gcd-euclidean.cpp)；复制到提交代码时，把 `gcdll` 和 `huajian` 两个函数一起复制，移除本地文件包含行。

```cpp
auto p = huajian(zi, mu);
cout << p.first;
if (p.second != 1) cout << '/' << p.second;
```

## 常见变体

根式系数 `u/v` 与普通分数共用约分函数，但打印规则不同：`u==1` 省略系数，`v==1` 省略分母。

## 易错点

- `6/-8` 要输出 `-3/4`，不能留下负分母。
- 判断是否输出分数应看分母是否为 1，不能要求分子必须为正。
- `0/7 -> 0`，`10/5 -> 2`，`-6/8 -> -3/4`。
- 有理部分为负数时仍然要打印；有理部分为零时，只省略该部分。

## 复杂度

时间 `O(log(min(|zi|,|mu|)+1))`，额外空间 `O(1)`。

用户已手写 `huajian` 并在有理部分和根式系数处调用。修正重点是符号规范和输出条件，不应为每种分子正负重复实现一套约分算法。
